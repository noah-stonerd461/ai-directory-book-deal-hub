## What is Ai-directory?

Ai-directory provides a searchable discovery interface for ebook promotions and price changes. It consolidates listings associated with Amazon Kindle, Flipkart, and Kobo so users can review current offers without visiting each marketplace separately.

The application follows a web-based architecture built around HTML5, JavaScript, and Express.js patterns. It supports readers tracking book prices, deal publishers, and anyone who needs an organized view of promotions, sorted listings, and alert-based updates.

---

## Core capabilities

- Refreshes deal and price information on an hourly basis
- Provides live search for quickly narrowing directory results
- Sorts listings dynamically according to different comparison criteria
- Displays specifications in a side-by-side comparison view
- Sends price-drop notifications through WhatsApp and email
- Records affiliate redirect activity for link telemetry
- Includes an administrative dashboard for directory and activity management
- Uses a web-first interface based on HTML5, JavaScript, and Express.js

## Using the directory

After the application starts, users can locate ebook deals, reorder results, and inspect multiple listings together.

A common browsing sequence is:

1. Load the directory in a web browser.
2. Search by title, platform, or deal category.
3. Apply sorting to bring the most useful offers to the top.
4. Check the comparison information before following an affiliate link.
5. Enable or use WhatsApp and email alerts to keep track of price changes.

Administrative users can work from the dashboard to maintain listings, inspect tracked items, and view redirect activity.
